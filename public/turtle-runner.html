Turtle Commands Quick Cheat-Sheet (Direct Syntax)

            

                

                    Movement:
                    
forward(100) - Move forward 100px

                    
backward(50) - Move backward 50px

                    
goto(x, y) - Jump to coordinates

                    
penup() / pendown() - Lift/drop pen

                

                

                    Turns & Shapes:
                    
right(90) - Turn right 90 degrees

                    
left(45) - Turn left 45 degrees

                    
circle(60) - Draw circle radius 60

                    
hideturtle() - Hide arrow cursor

                

                

                    Styling & Colors:
                    
pencolor("cyan") - Set pen color

                    
fillcolor("#f43f5e") - Set fill color

                    
width(3) - Line stroke thickness

                    
speed(0) - Set fastest draw speed

                    
bgcolor("#0f172a") - Canvas background
